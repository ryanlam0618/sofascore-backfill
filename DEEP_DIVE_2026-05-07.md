# SofaScore Deep Dive — hidden/secondary data sources (2026-05-07)

## Question
Re-check whether these are really unavailable:
- team rankings
- historical squads
- referees
- managers
- attendance

## Live findings

### 1) Team rankings
- Direct API patterns still fail with 404:
  - `/api/v1/rankings/team/world`
  - `/api/v1/rankings/team/country`
  - tested variants in `fetch_team_rankings.py`
- But team web pages embed rankings in HTML `__NEXT_DATA__`:
  - Example page: `https://www.sofascore.com/team/football/arsenal/42`
  - Path: `props.pageProps.initialProps.teamRankings.rankings`
  - Sample fields per row: `year`, `ranking`, `points`, `team`, `type`, `rankingClass`
- Confirmed on multiple clubs: Arsenal, Liverpool, Real Madrid.
- Therefore: **scrapeable via HTML hydration JSON, not public API**.

### 2) Historical squads
- `/api/v1/team/{id}/squad` returns 404.
- `/api/v1/team/{id}/players` returns 200 and includes current roster-like data.
- Adding `seasonId` / `season_id` query params also returns 200, but live tests suggest the param is ignored (same roster across multiple season IDs for Arsenal).
- Team HTML page includes:
  - `players` (current roster-like section)
  - `teamTransfers` with `transfersIn` / `transfersOut`
- Therefore: **no confirmed authoritative historical squad endpoint yet**.
- Possible reconstruction strategies:
  1. combine season match lineups across all events
  2. combine current roster + transfer history from team page
  3. inspect browser/network traffic for hidden squad-season source if any

### 3) Referees
- Confirmed directly available:
  - `/api/v1/event/{event_id}` contains `event.referee`
  - `/api/v1/referee/{referee_id}` returns referee profile data
- Therefore: **direct API available**.

### 4) Managers
- Confirmed directly available:
  - `/api/v1/team/{team_id}` contains `team.manager`
  - `/api/v1/manager/{manager_id}` returns manager profile data
- Therefore: **direct API available**.

### 5) Attendance
- Confirmed directly available:
  - `/api/v1/event/{event_id}` contains `event.attendance`
- Therefore: **direct API available**.

## Practical conclusion
- **Definitely available now:** referees, managers, attendance
- **Available via alternate path:** team rankings (HTML `__NEXT_DATA__`)
- **Still unresolved / partial:** historical squads

## Suggested next implementation order
1. Add scripts for referees / managers / attendance (easy direct API wins)
2. Build `team_rankings` scraper from team page `__NEXT_DATA__`
3. Deepen historical squad research separately (likely reconstruction, unless hidden browser source appears)
